# API

| Member | Meaning |
| --- | --- |
| `SpriteStack.load(path, sliceCount:)` | Loads a strip from a Flutter asset |
| `SpriteStack.decode(bytes, sliceCount:)` | Decodes a strip from memory |
| `SpriteStack.fromImage(image, sliceCount:)` | Wraps an already decoded `ui.Image` |
| `render(canvas, position:, yaw:, pitch:, roll:, rollPivot:, scale:, spacing:, sliceStep:, paint:, outline:, shadow:, outlineColor:, shadowColor:)` | Draws the stack |
| `sliceWidth`, `sliceHeight`, `sliceSize`, `sliceCount` | Strip geometry |
| `heightFor(pitch:, spacing:)` | Rendered height in source pixels |
| `boundsFor(yaw:, pitch:, roll:, rollPivot:, scale:, spacing:, outline:, shadow:)` | Projected bounds: `size` + `ground` point; the envelope is rotated by `roll` |
| `bake(yaw:, pitch:, roll:, rollPivot:, scale:, spacing:, frame:, ...)` | Renders once into a `BakedSpriteStack` |
| `frameCount` | Frames stored in the atlas (vertical rows) |
| `SpriteStack.defaultPitch` | `asin(0.75)` rad (~49°) |
| `dispose()` | Releases the decoded image |
| `SpriteStackPainter(...)` | `CustomPainter` for plain Flutter |
| `BakedSpriteStack` | A recorded frame; `draw(canvas, ground)` + `dispose()` |
| `SpriteStackTurntable(stack, buckets:, ...)` | Lazily baked frames per yaw bucket |
| `SpriteStackCache()` | Shares decoded stacks by asset path |
| `SpriteStackAnimation(stack, frameDuration:, loop:, pingPong:, ...)` | Plays the atlas frames |
| `SpriteStackAnimation.load(path, sliceCount:, frameCount:, ...)` | Loads an atlas and plays it |

`pitch` is clamped to `0..π/2` and its squash to `0.08..1`, so the stack never
collapses to nothing.

## Render parameters

| Parameter | Default | Meaning |
| --- | --- | --- |
| `position` | required | Bottom-centre ground contact point |
| `yaw` | `0` | Rotation around the vertical axis, radians |
| `pitch` | `defaultPitch` | Camera tilt, `0` (edge-on) to `π/2` (top-down) |
| `roll` | `0` | Screen-space tilt of the finished sprite, radians. A drawing effect, not a re-projection: it does not reveal a new side — turn `yaw` for that |
| `rollPivot` | `0` | Pivot of `roll` as a fraction of the body height above the anchor (`0` = feet planted, `0.5` = body middle) |
| `scale` | `1` | Uniform scale; keep it integer for crisp pixels |
| `spacing` | `1` | Lift between slices, source pixels |
| `outline` | `true` | Crisp 1 px outer outline around the finished stack |
| `shadow` | `true` | Projected ground shadow |
| `outlineColor` | `0xFF181C24` | Outline ink color |
| `shadowColor` | `0xFFBAC6D4` | Ground shadow color |
| `paint` | `null` | Optional paint, e.g. a color filter for the body |
| `pixelSnap` | `true` | Rounds the ground anchor (and fallback lifts) to whole pixels |
| `frame` | `0` | Atlas row to draw (clamped to `frameCount - 1`) |
| `motion` | `null` | `StackMotion` applied per slice |
| `time` | `0` | Clock fed to `motion`, in seconds |
| `cut` | `null` | `SliceCut` hiding slices above/below a frontier |
| `sliceStep` | `1` | Draws every `N`th cross-section (always keeping the ground and top slices); the scene derives it from distance |

## Scene

| Member | Meaning |
| --- | --- |
| `SpriteStackScene(camera:, zoom:, background:, sky:, ground:, objects:)` | Projects, depth-sorts and draws the props; `sky` wins over the flat `background` |
| `SpriteStackCamera.orbit(yaw:, pitch:, distance:, target:, near:)` | Camera on a sphere around `target`; `pitch` is clamped just short of top-down |
| `SpriteStackSceneObject(stack:, position:, yaw:, billboard:, roll:, rollPivot:, scale:, frame:, cut:, motion:, collider:)` | A prop; `position` is its ground point, `yaw` its world facing (`billboard: false`, the default) or a fixed screen facing (`billboard: true`), `roll` the screen-space bank, `collider` its collision proxy |
| `SpriteStackSky(top:, horizon:, bottom:, horizonFraction:)` | Gradient backdrop anchored to the ground plane's vanishing line |
| `SpriteStackGround(extent:, step:, color:, axisColor:, cellSize:, fill:, checker:, colorAt:, fadeColor:, fadeDistance:)` | Ground plane + grid; painted cells, procedural colors and distance fade |
| `SpriteStackFollowCamera(positionRate:, yawRate:, lookAhead:, height:, deadZone:)` | Third-person follow with exponential lag |
| `scene.paint(canvas, size)` | Projects and draws every object, far to near |
| `scene.projectObject(object, size)` | Screen ground point, depth, scale, render yaw, render pitch and bounds |
| `scene.horizonY(size)` | Screen y of the horizon; can fall outside the canvas |
| `scene.stats` | `drawn` / `culled` / `behindCamera` / `tooSmall` / `total` / `slicesDrawn` / `slicesTotal` / `sliceLodSaving` from the last paint |
| `scene.minimumProjectedPixels` | Props whose scaled bounds are smaller than this many pixels are skipped (default `0.5`) |
| `scene.sliceLod` | Drops cross-sections that land under a device pixel for distant props (default `true`) |
| `scene.sliceLodPixels` | Maximum screen distance between drawn slices when `sliceLod` is on (default `1`) |
| `SpriteStackSceneObject.sliceStep` | Manual slice decimation for one prop; `null` lets the scene choose |
| `scene.collisionBodyOf(object)` | Resolves one prop's `collider` to a world-space body, or `null` |
| `scene.collisionBodies(ignore:, stepHeight:)` | Every blocking body, skipping `ignore` and bodies no taller than `stepHeight` |
| `scene.blocks(position, radius:, ignore:, stepHeight:)` | Whether a ground circle overlaps a blocking body |
| `scene.move(position, delta:, radius:, ignore:, stepHeight:, maxSubsteps:)` | Sweeps a ground circle, sliding along bodies; returns a `SpriteStackMoveResult` |
| `SpriteStackFollowCamera.update(camera, subject:, yaw:, velocity:, dt:)` | Moves the camera target and yaw towards a subject |
| `SpriteStackFollowCamera.forwardOf(yaw)` | World direction a prop faces (front is `+Y`) |
| `SpriteStackFollowCamera.smoothing(rate, dt)` | `1 - exp(-rate * dt)`, the frame-rate independent factor |
| `SpriteStackFollowCamera.approachAngle(from, to, factor)` | Turns by the shortest arc |

## Collision

| Member | Meaning |
| --- | --- |
| `SpriteStackCollider(padding:, size:, offset:, height:, alphaThreshold:)` | Authored on `object.collider`; all lengths in art pixels, scaled by `object.scale` |
| `SpriteStackCollider.size` | Explicit footprint (`width` × slice `y` depth). `null` derives it from the stack volume |
| `SpriteStackCollider.padding` | Extra margin around the footprint, art pixels |
| `SpriteStackCollider.offset` | Footprint centre offset from the ground point, prop-local art pixels: `+y` is forward |
| `SpriteStackCollider.height` | Proxy height, art pixels; `null` derives it from the volume (unlimited with an explicit `size`) |
| `SpriteStackCollider.alphaThreshold` | Alpha that counts as solid when reading the volume (default `128`) |
| `SpriteStackCollisionBody(center:, halfWidth:, halfDepth:, yaw:, height:)` | A resolved, world-space box on the ground plane |
| `body.overlaps(point, radius)` | Circle vs rotated box test |
| `body.resolve(point, radius)` | Closest position outside the box, or `null` |
| `body.bounds` | World AABB of the rotated box, for debug drawing and broad phase |
| `SpriteStackMoveResult.position` / `.applied` / `.hits` / `.collided` | Where the move ended, what it applied, bodies touched and whether anything blocked |

## Detail and quality

| Member | Meaning |
| --- | --- |
| `SpriteStackSceneDetail(minimumProjectedPixels:, outlineMinimumPixels:, shadowMinimumPixels:, outlines:, shadows:)` | One preset of how much a scene draws |
| `SpriteStackSceneDetail.sharp` | Current behaviour: every pass on, no size floors |
| `SpriteStackSceneDetail.balanced` / `.fast` / `.minimal` | Cheaper steps: drop ink and shadow on small props, then no shadows, then no ink |
| `scene.applyDetail(detail)` | Writes a preset into the scene's switches |
| `scene.outlineMinimumPixels` / `shadowMinimumPixels` | Props smaller than this on both axes skip that pass (`0` = never) |
| `scene.drawOutlines` / `drawShadows` | Whole-pass switches |
| `scene.cacheStillFrames` | Replays the last frame while nothing that affects it changes |
| `scene.stillFrameHits` | How many paints came from the cache |
| `scene.clearStillCache()` | Drops the cached frame |
| `SpriteStackQualityGovernor(levels:, startLevel:, windowMs:, ...)` | Picks a level index from frame gaps |
| `governor.frame(gapMs, moving:, busy:)` | Returns the new `SpriteStackSceneDetail`, or `null` |
| `governor.level` / `governor.detail` / `governor.waitingForMotion` | Current state |
| `governor.reset()` | Back to the start level |

`cacheStillFrames` is off by default: it hashes the scene's fields, so a
`colorAt` that reads captured state, or a stack image swapped behind its back,
would not invalidate it. Call `clearStillCache()` when you dispose or replace a
stack.

## Animation

| Member | Meaning |
| --- | --- |
| `update(dt)` | Advances playback by `dt` seconds |
| `frame` | Visible frame index |
| `frameCount` | Number of frames in the atlas |
| `frameDuration` | Seconds each frame stays on screen |
| `loop` | Restart at the end (`true`) or stop on the last frame |
| `pingPong` | Bounce `0 → n-1 → 0` instead of wrapping |
| `play()` / `stop()` / `reset()` | Playback control; `reset()` rewinds and pauses |
| `isPlaying` / `isFinished` | Playback state |
| `onComplete` / `onFrame` | Callbacks for the end of a non-looping clip and frame changes |

## Motion

| Member | Meaning |
| --- | --- |
| `StackMotion(sway:, speed:, wave:, phase:, lean:)` | Per-slice deformation |
| `sway` | Oscillation amplitude at the tip, source pixels |
| `speed` / `wave` / `phase` | Angular speed, per-slice lag and initial phase (radians) |
| `lean` | Constant tip offset, source pixels (`+y` down) |
| `offsetAt(slice, sliceCount, time)` | Offset for one slice, using the `(z / (n-1))²` falloff |
| `isEmpty` | Whether the motion leaves every slice in place |

## Cutaways

| Member | Meaning |
| --- | --- |
| `SliceCut(top:, bottom:)` | Visible slice range, both frontiers continuous |
| `top` | First hidden slice counting from the ground (`19` keeps `0..18`) |
| `bottom` | Slices hidden at the ground |
| `isActive` / `isVisible(slice)` | Whether the cut hides anything / that slice |
| `visibilityAt(slice)` | `0..1`, fractional at the frontier |
| `visibleSliceCount(count)` | Surviving slices, used to shrink bounds |

## Baked frames

| Member | Meaning |
| --- | --- |
| `BakedSpriteStack.draw(canvas, groundPosition)` | Replays the frame with a single `drawPicture` |
| `BakedSpriteStack.bounds` | Projected bounds of that frame |
| `BakedSpriteStack.dispose()` | Releases the picture |
| `SpriteStackTurntable.buckets` | Number of baked yaw angles |
| `SpriteStackTurntable.frameFor(yaw)` | Frame closest to `yaw`, baked on first use |
| `SpriteStackTurntable.warmUp()` | Bakes every bucket up front |
| `SpriteStackTurntable.draw(canvas, ground, yaw)` | Draws the closest bucket |
| `SpriteStackCache.load(path, sliceCount:)` | Loads once, reuses afterwards |
| `SpriteStackCache.evict(path)` / `clear()` | Drops and disposes cached stacks |
