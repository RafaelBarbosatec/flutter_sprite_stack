# Game Engines (Flame / Bonfire)

The package deliberately ships **no engine component**. It only needs a
`Canvas`, so it stays free of Flame, Bonfire or any other engine version
constraint. You can use it in Flame, Bonfire, a plain `Ticker` loop or a custom
renderer by calling `render` from your own component.

## A minimal prop component

Wrap `SpriteStack.render` in any component that exposes `render(Canvas)` and
size it from the projected bounds:

```dart
class StackProp extends PositionComponent {
  StackProp({
    required this.stack,
    required Vector2 ground,
    this.yaw = 0,
    this.stackScale = 4,
  }) : super(position: ground, size: Vector2.zero()) {
    final bounds = stack.boundsFor(
      yaw: yaw,
      scale: stackScale,
    );
    size = Vector2(bounds.size.width, bounds.size.height);
  }

  final SpriteStack stack;
  final double yaw;
  final double stackScale;

  @override
  void render(Canvas canvas) {
    stack.render(
      canvas,
      position: Offset(size.x / 2, size.y), // ground point
      yaw: yaw,
      scale: stackScale,
    );
  }
}
```

`boundsFor` returns the **projected** bounds — rotated footprint, outline and
ground shadow — so hit boxes, camera culling and `priority`-based Y sorting
match what is actually drawn. `yaw` spins the prop in place; it does **not**
touch the component's own `angle`. The drawing stays anchored by its ground
point, so the prop does not slide while the bounds change.

## Animation

Drive a `SpriteStackAnimation` from your component's `update` and pass its
frame to `render`:

```dart
class AnimatedProp extends StackProp {
  AnimatedProp({
    required this.animation,
    required super.stack,
    required super.ground,
    super.yaw,
    super.stackScale,
  });

  final SpriteStackAnimation animation;

  @override
  void update(double dt) {
    super.update(dt);
    animation.update(dt);
  }

  @override
  void render(Canvas canvas) {
    stack.render(
      canvas,
      position: Offset(size.x / 2, size.y),
      yaw: yaw,
      scale: stackScale,
      frame: animation.frame,
    );
  }
}
```

## Wind, banners and vegetation

Pass a `StackMotion` and advance the clock yourself:

```dart
stack.render(
  canvas,
  position: ground,
  yaw: yaw,
  scale: 4,
  motion: const StackMotion(sway: 2.5, speed: 1.8),
  time: elapsedSeconds,
);
```

## Scenery that does not spin every frame

Skip the CPU rasterizer and replay a baked frame:

```dart
class BakedProp extends PositionComponent {
  BakedProp(this.baked, {super.position})
      : super(
          size: Vector2(
            baked.bounds.size.width,
            baked.bounds.size.height,
          ),
        );

  final BakedSpriteStack baked;

  @override
  void render(Canvas canvas) => baked.draw(canvas, baked.bounds.ground);

  @override
  void onRemove() {
    baked.dispose();
    super.onRemove();
  }
}
```

`SpriteStackTurntable` does the same for props that rotate: bake one `Picture`
per yaw bucket and draw the closest one.
