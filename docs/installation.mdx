# Installation

```bash
flutter pub add flutter_sprite_stack
```

Or add it manually to `pubspec.yaml`:

```yaml
dependencies:
  flutter_sprite_stack: ^0.1.0
```

Requires Flutter 3.22+ and Dart 3.5+. It works on every platform Flutter
supports, including web.
